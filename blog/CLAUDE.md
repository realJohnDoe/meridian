# Agent guidelines for blog/

## Don't edit published posts

`blog/` is already-published content. Do not edit it — not to fix a stale
claim, append a correction, update a screenshot, or otherwise make it match
the current state of the app — even as a side effect of an unrelated fix
(a README change, a survey finding, a rebrand) that happens to touch the
same topic.

If a post is factually out of date, that's for the user to handle
separately; don't take it on unless they explicitly ask you to edit a post.

See commit `3137b0d` ("Revert blog hero image change") for the precedent
this file codifies.
